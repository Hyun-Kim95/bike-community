# 에뮬레이터에서 소프트 키보드(화면 키보드) 켜기

텍스트 입력 시 키보드가 안 뜨면, 에뮬레이터가 **하드웨어 키보드**만 쓰도록 되어 있을 수 있습니다. 아래 중 한 가지 방법으로 **소프트 키보드**를 켜면 됩니다.

---

## 방법 1: 에뮬레이터 실행 중에 설정에서 끄기 (가장 쉬움)

1. **에뮬레이터가 켜진 상태**에서, 에뮬레이터 창 옆에 있는 **⋮ (세로 점 3개)** 버튼을 누릅니다.
2. **Settings** (설정)를 선택합니다.
3. **General** 탭에 **"Send keyboard input to device"** / **"Hardware keyboard"** 같은 항목이 있으면 끄기(체크 해제). **없다면** **Advanced** 탭에서 Keyboard 관련 항목을 찾아 끄기.
4. (최신 에뮬레이터는 General/Advanced에 이 옵션이 없을 수 있음. 그럴 땐 아래 방법 2·3 사용.)
5. 설정을 닫고, 앱에서 텍스트 입력 칸을 다시 눌러 **화면 키보드**가 뜨는지 확인.

> **정리**: “키보드 입력을 기기로 보내기”를 끄면, PC 키보드 대신 **에뮬레이터 화면 키보드**가 사용됩니다.

---

## 방법 2: 에뮬레이터 내부 Android 설정에서 켜기

1. 에뮬레이터 **홈 화면**에서 **Settings(설정)** 앱을 엽니다.
2. **System** → **Languages & input** (또는 **일반 관리** → **언어 및 입력**)로 들어갑니다.
3. **Physical keyboard** / **On-screen keyboard** / **가상 키보드** 관련 메뉴를 찾습니다.
   - **Show virtual keyboard** / **Show on-screen keyboard** 같은 옵션이 있으면 **켜기**합니다.
   - 또는 **Hardware – Show virtual keyboard** 를 **켜기**합니다.
4. 설정을 나간 뒤, 앱에서 입력 칸을 눌러 키보드가 뜨는지 확인합니다.

(에뮬레이터/Android 버전에 따라 메뉴 이름이 조금 다를 수 있습니다.)

---

## 방법 3: 터미널에서 에뮬레이터를 올바른 옵션으로 실행하기

에뮬레이터를 **처음부터** 소프트 키보드를 쓰도록 만들고 싶다면, AVD를 만들 때나 실행할 때 옵션을 줄 수 있습니다.

### 3-1. 사용 가능한 에뮬레이터 목록 보기

```bash
flutter emulators
```

또는 (Android SDK만 쓰는 경우):

```bash
emulator -list-avds
```

여기서 나오는 **에뮬레이터 ID** (예: `Pixel_4_API_34`)를 기억합니다.

### 3-2. 에뮬레이터 실행 (Flutter 사용 시)

```bash
flutter emulators --launch <에뮬레이터_ID>
```

예:

```bash
flutter emulators --launch Pixel_4_API_34
```

이렇게만 하면 **기본 설정**으로 실행됩니다.  
소프트 키보드를 강제로 쓰게 하려면, 아래 3-3처럼 **AVD 설정**에서 하드웨어 키보드를 끄는 편이 확실합니다.

### 3-3. AVD에서 “하드웨어 키보드” 끄기 (한 번만 설정)

1. **Android Studio**를 엽니다.
2. **Tools** → **Device Manager** (또는 **AVD Manager**)를 엽니다.
3. 사용하는 에뮬레이터 옆 **✎ (연필 아이콘)** 을 눌러 **Edit** 합니다.
4. **Show Advanced Settings** (고급 설정 표시)를 누릅니다.
5. **Keyboard** / **Hardware keyboard** 항목을 찾아서:
   - **Hardware keyboard present** (하드웨어 키보드 사용) 를 **체크 해제** 하거나,
   - **Enable keyboard input** 를 **끄기** 합니다.
6. **Finish** 로 저장한 뒤, 해당 AVD를 다시 실행합니다.

이렇게 하면 해당 에뮬레이터는 항상 **소프트 키보드**를 사용하게 됩니다.

---

## 방법 4: 명령줄에서 에뮬레이터 실행 시 옵션 주기 (고급)

에뮬레이터를 `emulator` 명령으로 직접 실행할 때, 하드웨어 키보드를 끌 수 있습니다.

```bash
emulator -avd <에뮬레이터_ID> -no-boot-anim -no-snapshot-load
```

하드웨어 키보드 비활성화는 보통 AVD 설정에서 하는 것이 더 안정적입니다.  
위 명령은 “부팅 애니메이션 없이, 스냅샷 로드 없이” 실행할 때 참고용입니다.

---

## 요약

| 상황 | 추천 방법 |
|------|-----------|
| 이미 에뮬레이터가 켜져 있음 | **방법 1**: 에뮬레이터 ⋮ → Settings → **Send keyboard input to device** 끄기 |
| 에뮬레이터 내부 설정으로 하고 싶음 | **방법 2**: Android 설정 → 언어/입력 → 가상 키보드 켜기 |
| 새로 실행할 때부터 소프트 키보드 쓰고 싶음 | **방법 3-3**: AVD Manager에서 해당 AVD 편집 → Hardware keyboard **끄기** |
| 터미널에서 실행만 하고 싶음 | **방법 3-2**: `flutter emulators --launch <에뮬레이터_ID>` 로 실행 후, 필요하면 방법 1 적용 |

가장 빠른 건 **방법 1**입니다.  
그래도 키보드가 안 뜨면 **방법 3-3**으로 AVD를 한 번 수정해 두면, 그 다음부터는 해당 에뮬레이터를 어떻게 실행해도 소프트 키보드가 사용됩니다.
